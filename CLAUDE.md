# Project
A 2D JRPG in the style of Final Fantasy VI. Learning project; built in milestones,
each independently shippable. Python + pygame.

## Working agreement
- Implement only the current milestone. The spec's DEFERRED list is hard scope — do
  not build deferred features, even if "easy". If something seems missing, ask.
- Small, reviewable changes. I review and commit; don't commit for me.
- Keep files focused per the spec's layout. No new dependencies beyond pygame
  without asking.
- Plan before coding: when given a new milestone, propose an implementation plan and
  flag ambiguities before writing code.
